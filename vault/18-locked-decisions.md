# Locked Decisions

Items that are fixed for the MPP prototype. Do not reopen without an explicit decision.

## Core Constraints
- ≤6-hour core path.
- Beginner+ outcome target.
- Data-driven dialogue and flags only. No new engine systems for content.
- Local-only saves. No accounts, no cloud, no backend.
- No voice input or speech recognition in the critical path.
- Single-speaker audio (DR L.V.S) with light pitch/formant processing. Clean originals kept.
- DR L.V.S owns language, speech order, dance vocabulary, and cultural framing. Content stays draft until confirmed.
- Character select sets the path flag that gates mid-game learning emphasis and climax type.
- Climax failure restarts only the sequence, not the area.

## Format
- Hybrid walking visual novel.
- Full chibi style with readable clothing silhouettes.
- Discrete small areas.
- Binary-choice climax: formal speech order (Sione) or tauʻolunga movement + reason with NPC joiners (Mele).

## Explicitly Out of Scope
- Multiplayer.
- Voice gating or recognition scoring.
- Inventory systems beyond simple flags.
- Free-text input.
- Intermediate or higher structures.
- Multiple islands.
- Separate study or quiz mode.
- Cloud saves or accounts.

## Hand-off Rules
- New content is data only.
- Debug jumps available to airport and wedding eve.
- Human-readable local save format.
- Document no-auth, no-server, no third-party SDKs.
