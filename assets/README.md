# Visual Assets

Starting point for image generation. Each file contains a ready-to-use description based on the vault clothing and location baselines.

Full chibi with readable clothing silhouettes. Consistent line weight, soft cel shading, warm tropical palette. Phone-screen readable. All assets draft until cultural review.

## Folders

- `backgrounds/` — Airport exterior, car ride, family house exterior/interior, market

Generate style references first, then characters, then backgrounds. Drop finished PNGs alongside these description files.
