# Visual Assets

Start with [the approved visual style and reference gallery](style-reference.md). Chris approved the chibi proportions, character/dialogue treatment, top-down overworld and exterior car ride on 2026-11-07 (Pacific/Auckland).

## Surfaces
- Top-down 2D exploration: compact connected routes, four-direction chibi sprites, visible roofs, paths, entrances and optional environmental language encounters.
- Larger conversation views: expressive chibi characters, matching portraits, cream/terracotta dialogue and choice panels.
- Exterior side-on car ride: layered roadside scenery and occupants visible through windows.

## Folders
- `characters/` — character briefs; preserve identity across sprites, portraits and costume stages.
- `backgrounds/` — location briefs; produce overhead exploration layouts separately from dialogue/travel backdrops.
- `demo/` — existing editable stand-ins; not final approved art or implemented overworld.

Use clothing and location vault baselines with the style contract. Language, cultural details and motifs require DR L.V.S review. Review screenshots are composition references, not production-ready sprite sheets. Export assets separately from text/UI; confirm dimensions and alignment in-engine before batch production.
